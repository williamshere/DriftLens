# Project Specification: DriftLens (Sociological Discourse & Network Drift Mapper)

## 1. System Overview
DriftLens is an open-source computational sociology and NLP analytics pipeline written in Python. It analyzes temporal text corpora (such as archived forum discussions, academic transcripts, or community threads) to quantify and visualize semantic shift, vocabulary polarization, and community network topology across discrete time slices.

### Target Objectives
- Ingest unstructured temporal text corpora into a local SQLite store.
- Batch generate dense vector embeddings locally using Hugging Face / SentenceTransformers.
- Compute temporal semantic centroids per keyword/tag and calculate drift via Cosine Distance.
- Construct co-occurrence / interaction graph networks across time slices using NetworkX.
- Expose an interactive visual exploration dashboard via a local FastAPI backend and web canvas or PyVis.

---

## 2. Technical Stack & Dependencies
- **Runtime:** Python 3.12+ (or 3.14)
- **Data Persistence:** SQLite3 with WAL mode enabled (`sqlite3`)
- **Data Modeling & Validation:** `pydantic >= 2.0`
- **Embeddings & Vector Operations:** `sentence-transformers`, `numpy`, `scipy`
- **Graph & Network Analysis:** `networkx`
- **Backend API:** `fastapi`, `uvicorn`
- **CLI & Orchestration:** `click` or `argparse`
